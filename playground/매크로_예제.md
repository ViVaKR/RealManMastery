# 매크로

어셈블리는 명령어 하나가 손가락 한 마디 수준으로 잘게 쪼개져 있어서, 매크로를 얼마나 예술로 짜느냐에 따라 코드 길이가 10분의 1로 줄어들고 가독성이 결정됩니다.
Apple Silicon M4(ARM64) Clang 환경에 100% 최적화된 
"어셈블리 매크로 심화 과정"

------------------------------
## 🎓 Clang/GAS 어셈블리 매크로 심화 마스터 강좌## 1. 인자(Parameter) 핸들링의 모든 것 (지정, 기본값, 필수값)
매크로에 인자를 넘길 때, 단순히 순서대로 받는 것을 넘어 다양한 제약을 걸어 안전장치를 만들 수 있습니다.
## 📌 문법 요약

* 인자명:req: 해당 인자는 호출할 때 무조건(Required) 입력해야 합니다. 누락되면 컴파일러가 에러를 뱉습니다.
* 인자명=기본값: 호출할 때 인자를 안 주면 자동으로 설정되는 디폴트 값입니다.
* 인자명:vararg: 컴파일러가 크기를 알 수 없는 가변 인자(나머지 전부)를 묶어서 한 번에 받습니다.

## 💻 실전 예제: ARM64 다목적 비트 연산 매크로

/* 
   [설명] 특정 레지스터의 비트를 제어하는 매크로
   - dest: 무조건 지정해야 함 (:req)
   - src: 안 적으면 dest 레지스터 자체를 가리킴 (=dest)
   - bit: 안 적으면 기본값 0번 비트 제어 (=0)
*/
.macro BIT_CONTROL dest:req, src=\dest, bit=0
    and \dest, \src, #(1 << \bit)
.endm
// --- 활용법 ---
BIT_CONTROL x0          // 결과: and x0, x0, #(1 << 0)
BIT_CONTROL x0, x1, 4   // 결과: and x0, x1, #(1 << 4)

## 2. 문자열 결합(\.)과 가변 인자(:vararg) 심화
어셈블리 매크로 안에서 텍스트나 레지스터 이름을 조립(Concatenation)하거나, 수많은 레지스터 목록을 한 번에 다뤄야 할 때 씁니다. 이때 점(\.) 기호를 사용해 텍스트를 달라붙게 만듭니다.
## 💻 실전 예제: Apple M4 벡터(NEON) 레지스터 조립 매크로
ARM64의 벡터 연산은 레지스터 뒤에 .4s(32비트 4개), .2d(64비트 2개) 같은 크기 접미사를 붙여야 합니다. 이를 매크로로 조립해 주는 기교입니다.

/* 
   [설명] 벡터 덧셈 명령어 조립 매크로
   - type에 4s나 2d를 넣으면 명령어와 레지스터 뒤에 착 달라붙음
*/
.macro VECTOR_ADD type, v1, v2, v3
    add\.\type  \v1\.\type, \v2\.\type, \v3\.\type
.endm
// --- 활용법 ---
VECTOR_ADD 4s, v0, v1, v2   // 결과: add.4s v0.4s, v1.4s, v2.4s (32비트 4개 동시 덧셈!)

## 💻 실전 예제: 복수 레지스터 스택 저장 매크로 (:vararg)
여러 레지스터를 한 번에 대피시켜야 할 때 가변 인자를 사용합니다.

/* [설명] 다량의 레지스터를 한 번에 푸시(Push)하는 매크로 */
.macro PUSH_REGS list:vararg
    stp \list, [sp, #-16]!   // 기교: 인자로 들어온 레지스터 쌍을 스택에 박아 넣음
.endm
// --- 활용법 ---
PUSH_REGS x19, x20           // 결과: stp x19, x20, [sp, #-16]!

## 3. 매크로 탈출 지시자 (.exitm)
조건부 컴파일(.if)과 조합하여, 특정 조건이 만족되면 매크로 해석을 그 자리에서 즉시 중단하고 빠져나오는 강력한 지시자입니다. C언어 반복문의 break와 비슷한 역할을 합니다.
## 💻 실전 예제: 디버그 모드 전용 하드코딩 탈출

.set DEBUG_MODE, 1           // 디버그 스위치 켬

.macro ANALYZE_DATA reg
    .if DEBUG_MODE == 1
        // 디버그 모드일 때는 아래 복잡한 연산을 안 하고 즉시 탈출!
        mov \reg, #0
        .exitm               // 매크로 종료 (아래 코드는 컴파일 안 됨)
    .endif

    // [운영 환경용 복잡한 로직]
    mul \reg, \reg, \reg
    add \reg, \reg, #42
.endm

## 4. 매크로의 꽃: 루프 돌리기 (.irp 와 .irpc)
매크로 안에서 반복문을 돌려 수십 줄의 노가다 코드를 단 한 번에 찍어낼 수 있는 최고급 기교입니다. 중세 시대 문서에서 가장 불친절하게 설명하는 파트이기도 합니다.

* .irp (Iterate Repeat Parameter): 주어진 단어 목록을 순회합니다.
* .irpc (Iterate Repeat Character): 주어진 문자열의 글자 하나하나를 순회합니다.

## 💻 실전 예제: 범용 레지스터 일괄 초기화 (.irp)
함수를 시작할 때 보안이나 초기화를 위해 내 레지스터들을 싹 다 0으로 밀어버려야 할 때 사용합니다.

.macro CLEAR_SCRATCH_REGS
    // 주어진 레지스터 목록을 돌아가며 \r 자리에 넣고 반복 생성
    .irp r, x0, x1, x2, x3, x4, x5
        mov \r, #0
    .endp                    // .irp의 짝꿍 종료 지시자
.endm
// --- 활용법 ---
CLEAR_SCRATCH_REGS// [컴파일러가 실제로 뱉는 코드]// mov x0, #0// mov x1, #0// ...// mov x5, #0  (손 노가다 해방!)

## 💻 실전 예제: 순차적 텍스트 라벨 생성 (.irpc)
글자 한 자씩 뜯어서 라벨이나 데이터 테이블을 연속으로 조립할 때 씁니다.

.macro CREATE_LABELS
    // 1, 2, 3 글자를 하나씩 뜯어서 \num에 대입
    .irpc num, 123
        .L_step_\num:
            nop
    .endr                    // .irpc의 짝꿍 종료 지시자
.endm
// --- 활용법 ---
CREATE_LABELS// [컴파일러가 실제로 뱉는 코드]// .L_step_1: nop// .L_step_2: nop// .L_step_3: nop

## 5. 💡 Apple M4 실전 종합 예술: 시스콜 & 로깅 프레임워크
위에서 배운 심화 기술들을 총동원하여, 애플 실리콘 macOS 환경에서 실제로 동작하는 "가독성 끝판왕 시스템 콜 매크로 패키지"를 만들면 다음과 같습니다.

#pragma once                 // 구석기 가드 대신 현대적 가드 사용 😉
/* 1. 고유 라벨(\@)과 인자 기본값(=)을 활용한 안전한 에러 체크 매크로 */
.macro CHECK_ERROR reg, exit_code=1
    cmp \reg, #0
    b.ge .L_success_\@       // 에러가 없으면(0 이상이면) 점프
    
    // 에러 발생 시 프로그램 강제 종료 (exit 시스콜)
    mov x0, #\exit_code      // 디폴트 종료 코드 1
    mov x16, #1              // macOS exit 시스콜 번호
    svc #0x80                // 커널 호출
.L_success_\@:
.endm
/* 2. 문자열 결합(\.)과 가변 인자를 활용한 Mach-O 함수 정의 표준 프레임 */
.macro EXPORT_M4_FUNC name:req
    .global _\name
    .p2align 2
_\name:
    // M4 하드웨어 포인터 인증(PAC) 서명 적용
    pacibsp
    stp x29, x30, [sp, #-16]!
    mov x29, sp
.endm

.macro PURGE_M4_FUNC
    ldp x29, x30, [sp], #16
    autibsp                  // PAC 서명 검증
    ret
.endm

## 📝 강좌 요약 한눈에 보기 (치트시트)

| 지시자 | 역할 | 심화 포인트 |
|---|---|---|
| \인자명 | 인자 참조 | \.을 붙이면 뒤에 오는 텍스트와 빈칸 없이 강제 결합됨 |
| 인자:req | 필수 인자 지정 | 누락 시 컴파일 에러 유도로 버그 방지 |
| 인자:vararg | 가변 인자 묶음 | stp \list, [sp] 처럼 다중 레지스터 처리 시 필수 |
| .exitm | 매크로 즉시 탈출 | .if 조건문과 연동하여 컴파일 타임 최적화 |
| .irp | 단어 리스트 반복 | 여러 레지스터를 타겟으로 동일 명령을 복사할 때 씀 |
