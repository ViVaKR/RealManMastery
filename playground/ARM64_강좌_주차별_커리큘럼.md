# ARM64 어셈블리 강좌 — 주차별 커리큘럼

> 고급언어 학습 순서(자료형 → 변수 → 연산자 → 제어문 → 함수 → 배열/포인터)에
> 대응하되, ARM64의 실제 원리(레지스터·스택·분기·주소계산)로 자연스럽게 이어지도록 구성.

---

## 1주차 — 오리엔테이션 & 개발 환경
- ARM64(AArch64) 개요, RISC vs CISC 간단 비교
- 개발/실습 환경 구축 (QEMU, gcc/clang, gdb, objdump)
- 어셈블리 소스 → 어셈블 → 링크 → 실행 파이프라인 이해
- 첫 번째 프로그램: "Hello World" (시스템 콜 or libc 호출)

**실습 목표**: 어셈블리 코드를 직접 빌드하고 실행해본다.

---

## 2주차 — 레지스터와 "자료형"
- 범용 레지스터 개요: X0~X30, SP, PC
- W(32bit) vs X(64bit) 레지스터 — 고급언어의 `int` vs `long` 감각으로 연결
- 정수 부호/비부호 표현, 데이터 크기별 명령 접미사(B/H/W/X)
- 부동소수점/SIMD 레지스터(S/D) 살짝 소개 (심화는 후반부)
- MOV, MOVZ, MOVK, MOVN — 즉치값 로딩

**실습 목표**: "자료형 = 저장 공간의 크기와 해석"이라는 개념을 코드로 확인.

---

## 3주차 — 저장 위치: 레지스터 / 스택 / 메모리
- "변수 선언"이 없다는 개념 — 값을 어디에 둘 것인가
- 스택 구조와 SP, 스택 프레임 기초
- LDR/STR 기본 (레지스터 ↔ 메모리)
- 전역 변수 접근: ADRP + ADD 패턴
- 정렬(alignment)과 엔디언 개념

**실습 목표**: 지역변수를 스택에, 전역변수를 메모리에 저장/로드하는 코드 작성.

---

## 4주차 — 산술/논리 연산자
- ADD, SUB, MUL, SDIV/UDIV, MOD(계산 패턴)
- 논리 연산: AND, ORR, EOR, MVN
- 시프트: LSL, LSR, ASR, ROR
- 고급언어 연산자(`+ - * / % << >> & | ^`)와의 1:1 대응표 제공

**실습 목표**: 사칙연산 계산기를 어셈블리로 구현.

---

## 5주차 — 조건 플래그와 비교
- NZCV 플래그 이해 (Negative, Zero, Carry, Overflow)
- CMP, CMN, TST, CCMP
- 조건 코드(EQ, NE, GT, LT, GE, LE, HI, LO...) 총정리
- CSEL, CSET 등 조건부 데이터 처리 명령 (분기 없는 조건문)

**실습 목표**: 두 수 비교 후 조건에 따라 다른 값 저장(분기 없이도 가능함을 체험).

---

## 6주차 — 분기의 원리: if / while / for
- **핵심 개념**: "if/for/while은 문법이 아니라 CMP + B.cond + B의 조합"
- 무조건 분기 B, 조건 분기 B.cond
- if / if-else 패턴 구현
- while, for 루프 패턴 구현 (전위검사 vs 후위검사)
- 루프 언롤링 살짝 맛보기

**실습 목표**: 고급언어로 짠 if/for 코드를 손으로 어셈블리로 변환.

---

## 7주차 — switch문과 점프 테이블
- 단순 CMP 체인 방식의 switch 구현
- 점프 테이블 방식: ADR + LDR + BR
- 컴파일러가 실제로 switch를 어떻게 최적화하는지 objdump로 비교 분석

**실습 목표**: C의 switch문을 컴파일 후 역어셈블해서 패턴 분석.

---

## 8주차 — 중간 점검 & 미니 프로젝트 1
- 1~7주차 통합 복습
- 미니 프로젝트: 간단한 계산기 또는 성적 처리 프로그램 (자료형+제어문 종합)
- 코드 리뷰 및 디버깅 실습 (gdb 활용)

---

## 9주차 — 함수와 호출 규약 (AAPCS64)
- 함수 호출의 원리: BL / RET
- 인자 전달 규약: X0~X7 (정수), V0~V7 (부동소수점)
- 리턴값 전달: X0 (또는 X0/X1 쌍)
- 스택 프레임 생성/해제, 16바이트 정렬 규칙
- Caller-saved vs Callee-saved 레지스터 (X19~X28)

**실습 목표**: 파라미터를 받는 함수와 이를 호출하는 코드 작성.

---

## 10주차 — 재귀 함수와 스택 프레임 심화
- LR(X30) 저장/복원, 중첩 함수 호출
- 재귀 함수 구현 (팩토리얼, 피보나치)
- 스택 오버플로우 이해
- 프롤로그/에필로그 패턴 정형화

**실습 목표**: 재귀 함수를 어셈블리로 직접 구현.

---

## 11주차 — 배열과 주소 연산
- 배열 인덱싱 = base + offset 주소 계산
- Addressing mode 총정리: 즉치 오프셋, 레지스터 오프셋(+시프트), pre/post-index
- 1차원/2차원 배열 순회 구현
- 포인터 연산 = 정수 덧셈이라는 것 명확히 하기

**실습 목표**: 배열 합계/최댓값 찾기 프로그램 구현.

---

## 12주차 — 구조체와 복합 자료구조
- 구조체 필드 오프셋 상수화
- 구조체 배열 접근
- 간단한 연결 리스트(포인터 기반) 구현
- 문자열 처리 기초 (NUL-terminated string 순회)

**실습 목표**: 간단한 학생 정보 구조체 배열 프로그램 작성.

---

## 13주차 — SIMD/NEON 맛보기 & 최적화 기초
- SIMD 레지스터(V0~V31)와 벡터 연산 개념
- 간단한 벡터 덧셈/곱셈 실습
- 컴파일러 최적화 옵션(-O0~-O3)에 따른 코드 변화 비교
- 인라인 어셈블리(C 코드 내 asm 삽입) 소개

**실습 목표**: 벡터 연산 간단 실습 + 최적화 전후 코드 비교.

---

## 14주차 — 시스템 콜 & C 라이브러리 연동
- Linux AArch64 시스템 콜 규약 (SVC 명령, X8=시스템콜 번호)
- 파일 입출력 시스템 콜 실습
- C 함수와의 상호 호출(어셈블리에서 printf 호출 등)

**실습 목표**: 파일을 읽고 쓰는 간단한 프로그램 구현.

---

## 15주차 — 종합 프로젝트 & 발표
- 최종 미니 프로젝트: 지금까지 배운 것 종합 (자료형+제어문+함수+배열+구조체)
- 예: 간단한 계산기, 정렬 알고리즘, 텍스트 처리 도구 중 택1
- 코드 리뷰 및 발표

---

## 16주차 — 총정리 & Q&A
- 전체 커리큘럼 리뷰
- 고급언어 ↔ ARM64 대응표 최종 정리본 배포
- 추가 학습 로드맵 안내 (커널 프로그래밍, 리버스 엔지니어링, 임베디드 등)
