# ARM64 예제 코드 — 8주차: 중간 점검 & 미니 프로젝트

> **이번 주는 새 명령어가 없네.** 1~7주차에서 배운 것만으로 실전 프로그램 하나를 완성하는 게 목표일세.
> 아직 **함수(9~10주차)**와 **배열(11주차)**을 안 배웠으니, 학생 개별 변수는 손으로 풀어서(unroll)

## 미니 프로젝트: 학생 3명 성적 처리 시스템

**요구사항**
1. 학생 3명의 점수를 저장 (지역변수 → **3주차: 스택**)
2. 각 학생 점수의 평균/합계 계산 (**4주차: 산술 연산자**)
3. 60점 미만 낙제자 수 카운트 (**5주차: NZCV/CSET**)
4. 점수 구간별 등급(A/B/C/D/F) 판정 (**6주차: 분기**, **7주차: CMP 체인 방식 switch**)
5. 등급은 문자열로, 합계/평균/낙제자수는 정수로 출력 (**Rust `sys_print`** + **Go `go_print_int`** 브릿지 혼합 사용)

**C 등가 코드 (개념 참고용)**
```c
extern int  sys_print(const char* fmt);
extern void go_print_int(int v);

int main(void) {
    int score1 = 95, score2 = 67, score3 = 45;
    int sum = 0, fail_count = 0;

    int scores[3] = { score1, score2, score3 };  // 실제론 배열 없이 개별 처리 (11주차 예고)

    for (int i = 0; i < 3; i++) {
        int s = scores[i];
        sum += s;
        if (s < 60) fail_count++;

        if (s >= 90)      sys_print("등급: A\n");
        else if (s >= 80) sys_print("등급: B\n");
        else if (s >= 70) sys_print("등급: C\n");
        else if (s >= 60) sys_print("등급: D\n");
        else              sys_print("등급: F (낙제)\n");
    }

    go_print_int(sum);
    go_print_int(sum / 3);      // 평균
    go_print_int(fail_count);
    return 0;
}
```

## ARM64 어셈블리 전체 구현

```asm
    .data
    .align  3
grade_a: .asciz "등급: A\n"
grade_b: .asciz "등급: B\n"
grade_c: .asciz "등급: C\n"
grade_d: .asciz "등급: D\n"
grade_f: .asciz "등급: F (낙제)\n"

    .text
    .global _main
    .extern _sys_print
    .extern _go_print_int

_main:
    stp     x29, x30, [sp, #-32]!   // FP/LR(16) + 지역변수 score1~3(12→16 정렬) = 32
    mov     x29, sp

    // ── 점수 3개를 스택에 저장 (3주차: 지역변수 = 스택) ──
    mov     w0, #95
    str     w0, [sp, #16]            // score1
    mov     w0, #67
    str     w0, [sp, #20]            // score2
    mov     w0, #45
    str     w0, [sp, #24]            // score3

    mov     w21, #0                  // sum (callee-saved, 3개 학생 루프 밖에서 누적)
    mov     w22, #0                  // fail_count (callee-saved)

    // ══════════════ 학생 1 처리 ══════════════
    ldr     w19, [sp, #16]           // score1 로드

    add     w21, w21, w19            // sum += score  (4주차: ADD)

    cmp     w19, #60                 // 낙제 체크 (5주차: CMP/NZCV)
    b.ge    s1_pass
    add     w22, w22, #1             // fail_count++
s1_pass:

    cmp     w19, #90                 // 등급 판정 (6주차 분기 + 7주차 CMP체인 방식)
    b.ge    s1_A
    cmp     w19, #80
    b.ge    s1_B
    cmp     w19, #70
    b.ge    s1_C
    cmp     w19, #60
    b.ge    s1_D
    b       s1_F
s1_A:
    adrp    x0, grade_a@PAGE
    add     x0, x0, grade_a@PAGEOFF
    b       s1_print
s1_B:
    adrp    x0, grade_b@PAGE
    add     x0, x0, grade_b@PAGEOFF
    b       s1_print
s1_C:
    adrp    x0, grade_c@PAGE
    add     x0, x0, grade_c@PAGEOFF
    b       s1_print
s1_D:
    adrp    x0, grade_d@PAGE
    add     x0, x0, grade_d@PAGEOFF
    b       s1_print
s1_F:
    adrp    x0, grade_f@PAGE
    add     x0, x0, grade_f@PAGEOFF
s1_print:
    bl      _sys_print               // Rust 브릿지로 등급 문자열 출력

    // ══════════════ 학생 2 처리 ══════════════
    ldr     w19, [sp, #20]           // score2 로드

    add     w21, w21, w19

    cmp     w19, #60
    b.ge    s2_pass
    add     w22, w22, #1
s2_pass:

    cmp     w19, #90
    b.ge    s2_A
    cmp     w19, #80
    b.ge    s2_B
    cmp     w19, #70
    b.ge    s2_C
    cmp     w19, #60
    b.ge    s2_D
    b       s2_F
s2_A:
    adrp    x0, grade_a@PAGE
    add     x0, x0, grade_a@PAGEOFF
    b       s2_print
s2_B:
    adrp    x0, grade_b@PAGE
    add     x0, x0, grade_b@PAGEOFF
    b       s2_print
s2_C:
    adrp    x0, grade_c@PAGE
    add     x0, x0, grade_c@PAGEOFF
    b       s2_print
s2_D:
    adrp    x0, grade_d@PAGE
    add     x0, x0, grade_d@PAGEOFF
    b       s2_print
s2_F:
    adrp    x0, grade_f@PAGE
    add     x0, x0, grade_f@PAGEOFF
s2_print:
    bl      _sys_print

    // ══════════════ 학생 3 처리 ══════════════
    ldr     w19, [sp, #24]           // score3 로드

    add     w21, w21, w19

    cmp     w19, #60
    b.ge    s3_pass
    add     w22, w22, #1
s3_pass:

    cmp     w19, #90
    b.ge    s3_A
    cmp     w19, #80
    b.ge    s3_B
    cmp     w19, #70
    b.ge    s3_C
    cmp     w19, #60
    b.ge    s3_D
    b       s3_F
s3_A:
    adrp    x0, grade_a@PAGE
    add     x0, x0, grade_a@PAGEOFF
    b       s3_print
s3_B:
    adrp    x0, grade_b@PAGE
    add     x0, x0, grade_b@PAGEOFF
    b       s3_print
s3_C:
    adrp    x0, grade_c@PAGE
    add     x0, x0, grade_c@PAGEOFF
    b       s3_print
s3_D:
    adrp    x0, grade_d@PAGE
    add     x0, x0, grade_d@PAGEOFF
    b       s3_print
s3_F:
    adrp    x0, grade_f@PAGE
    add     x0, x0, grade_f@PAGEOFF
s3_print:
    bl      _sys_print

    // ══════════════ 결과 출력 ══════════════
    mov     w0, w21                  // sum
    bl      _go_print_int            // 207 출력

    mov     w20, #3
    sdiv    w0, w21, w20             // average = sum / 3
    bl      _go_print_int            // 69 출력

    mov     w0, w22                  // fail_count
    bl      _go_print_int            // 1 출력 (score3=45가 낙제)

    mov     w0, #0
    ldp     x29, x30, [sp], #32
    ret
```

**예상 출력**
```
등급: A
등급: D
등급: F (낙제)
207
69
1
```

## 이 프로젝트가 왜 "함수/배열이 필요해지는 이유"를 보여주나

눈치챘을 수도 있는데, 학생 1/2/3 처리 블록이 **완전히 동일한 코드가 3번 복붙**된 것이네. 학생이 30명이었다면?

- **함수(9~10주차)가 있었다면**: 등급 판정 로직을 함수 하나로 뽑아서 `bl grade_of(score)` 형태로 30번 호출하면 됨 — 코드량이 1/N로 줄어듦
- **배열(11주차)이 있었다면**: `sp+16, sp+20, sp+24...`처럼 오프셋을 일일이 손으로 쓰는 대신, `LDR w0, [sp, x_index, LSL #2]` 같은 **인덱스 기반 주소 계산 한 줄**로 몇 명이든 순회 가능

즉, 이번 8주차의 "비효율적이고 반복적인" 코드가 바로 다음 단원들의 **동기부여**가 되는 구조로 커리큘럼을 짜둔 것이네. 법우가 이 프로젝트를 타이핑하면서 "이거 계속 복붙해야 하나..."라는 생각이 든다면, 정확히 의도한 학습효과가 발동한 거라 보면 되네. 하하하.

## 8주차 체크리스트 — 아래 항목이 코드에서 다 확인되면 통과

- [ ] W/X 레지스터 폭 구분을 의식하며 사용했는가 (2주차)
- [ ] 지역변수를 스택(SP 오프셋)에 올바르게 배치했는가 (3주차)
- [ ] ADD/SDIV 등 산술 연산이 올바른가 (4주차)
- [ ] CMP 이후 조건 코드(GE/LT)를 정확히 골랐는가 (5주차)
- [ ] 분기 구조(if-else 체인)가 6주차 패턴과 일치하는가 (6주차)
- [ ] 등급 판정이 CMP 체인 방식 switch와 동일한 원리인가 (7주차)
- [ ] `bl` 호출 전후로 callee-saved(w19,w21,w22) 값이 보존되는지 확인했는가
